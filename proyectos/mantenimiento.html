Gestión de mantenimiento2024

Proyecto final de la Tecnicatura en Programación (UTN), hecho en equipo. El área de mantenimiento de un edificio necesita saber qué activos hay, dónde está cada uno, qué tareas requieren y qué operario las hace. El sistema registra todo eso y genera órdenes de trabajo. Desarrollé el backend y el frontend.

  • Backendgithub.com/hernangaston/mantenimiento
  • Frontendgithub.com/hernangaston/mantenimiento_front
  • StackNode.js, Express, MySQL, JWT, Angular 18, Swagger, Docker

# Qué incluye

  • API REST con Express y MySQL para 13 recursos, documentada con Swagger.
  • Registro y login con bcrypt y JWT; todas las rutas de la API exigen token.
  • Frontend en Angular 18 con guards por rol y un interceptor que envía el token y cierra la sesión cuando vence.
  • Base de datos en Docker Compose.
